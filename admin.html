对话

上下文条数 = 每次发给模型的最近消息数（系统提示词不计入）；输出上限 = 单次回答最多生成的 token（用户可在自己的设置里调低，不能超过这里的上限）。模型列表里可为单个模型设置 max_tokens 与最大上下文：max_tokens 留空跟随此处，最大上下文填该模型的窗口大小（token），发送时按「窗口 − 预估输入」自动压缩输出、并裁剪过长的历史消息。温度留空则不发送该参数；推理型模型（如 o 系列、DeepSeek R1）可能不接受 temperature，被拒时会自动去参重试。

调用上游 AI 接口的最长等待时间。生成长文或使用较慢的模型/平台时适当调大。若上游根本连不上（地址错误、网络不通），会更快返回明确提示，不受此值影响。

AI 思考策略

统一管理各模型的推理强度。规则按顺序匹配模型 ID(包含匹配),第一个命中生效;无命中时用全局默认。「自动学习」在上游报错时记录可用档位并生成规则,确保后续请求可用。

用户验证与 SMTP

注册与账号安全

关闭后登录页不再显示注册入口，注册接口也会直接拒绝（已有账号可正常登录）。

游客体验

开启后，未登录访客访问首页即可直接对话。每位访客会自动创建一个独立游客账号（命名如「游客A1B2C」并归入「游客」用户组），便于在「用户」列表里单独管理与清理。游客额度在「模型授权」中按游客组控制，轮数在下方设置。

会话有效期修改后对新登录生效；「强制全站下线」会使所有人的现有登录态立即失效（包括你自己），需要重新登录。

SMTP

额度套餐

一个套餐一张卡片，用户端展示同样内容。价格填 0 时可被用户直接领取（每人限领一次）；付费套餐用购买链接或兑换码。

兑换码使用情况

按套餐生成的随机兑换码与手动添加的固定兑换码都在此列出：状态、使用者与过期时间。「清理已使用」只删除已核销的记录。

生成兑换码

为某个「额度套餐」批量生成随机兑换码。新生成的码会同时保存明文，可在左侧「兑换码使用情况」中按套餐导出；旧版生成的码只有哈希，无法导出明文。

按套餐批量操作

导出所选套餐全部未使用兑换码的明文（一行一个，.txt 文件）；清除则删除所选套餐全部未使用的兑换码，已使用的不受影响。

添加固定兑换码

自定义码面（如 WELCOME2026），适合做活动通用码。可设置总兑换次数与每次兑换获得的额度；开启「每个用户限兑一次」后同一账号只能使用一次。

联网搜索

开启后，对话会先检索网页再作答，回复底部附来源链接。

Tavily 需在 tavily.com 申请 Key。SearXNG 每行一个实例根地址，需开启 JSON 格式（format=json）；对话检索按顺序尝试，当前实例失败或没有结果时自动换下一个。探测会拉取 searx.space 使用的官方公共目录（约 80 个 HTTPS 实例）并分批测试，可用的排在前面，点「填入」会追加到列表。

文档解析

支持 PDF、图片、Word、PPT、Excel、HTML。Token 留空走 MinerU 轻量解析；填入后改用精准解析。解析不扣对话次数。

当前：轻量解析。单文件不超过 10MB、20 页，同一 IP 每分钟有次数限制。用户上传后直接解析，只有超限或失败时才会看到限制。

版本更新

从 GitHub Releases 检查新版本并在线升级。更新只覆盖程序文件，data/ 数据目录与 config.php 不会被改动；升级前的程序会自动备份到 data/update/backup/。需要主机可访问更新源（config.php 可配镜像）且 PHP 启用 zip 或 phar 扩展。
